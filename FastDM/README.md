# FastDM — مدير تنزيلات سريع (Kotlin + Jetpack Compose)

مدير تنزيلات لأندرويد مستوحى من 1DM.

## المزايا
- تنزيل على أجزاء متوازية (حتى 16 جزءاً لكل ملف) لزيادة السرعة، وشريط تقدّم يعرض الأجزاء فعلياً
- إيقاف مؤقت واستئناف من نفس البايت (حتى بعد إغلاق التطبيق)، مع إعادة المحاولة التلقائية
- **تحديث الرابط**: ألصق رابطاً جديداً لنفس الملف، أو اضغط «التقاط من المتصفح» وابدأ التنزيل من الصفحة ليُلتقط الرابط الجديد تلقائياً (يتحقق التطبيق أن حجم الملف لم يتغير)
- تحديد عدد التنزيلات المتزامنة وعدد الأجزاء من الإعدادات، مع طابور انتظار
- متصفح مدمج كامل: تبويبات، شريط عنوان ذكي (بحث/رابط)، وضع سطح المكتب، رفع الملفات، فيديو بملء الشاشة، التقاط التنزيلات تلقائياً، ضغطة مطوّلة على الرابط للتنزيل
- مانع إعلانات: حظر النطاقات الإعلانية والمتتبعات + إخفاء عناصر الإعلانات + حظر النوافذ المنبثقة، مع زر لتحديث القائمة من الإنترنت
- شاشة `presplash.png` لمدة 3 ثوانٍ عند الفتح
- واجهة عربية/إنجليزية، وضع داكن/فاتح تلقائي، إشعار تقدّم مع زر «إيقاف الكل»
- يستقبل الروابط من «مشاركة» ومن فتح روابط http/https

## استبدال شاشة البداية
ضع صورتك في:
`app/src/main/res/drawable/presplash.png`
(الملف الموجود حالياً صورة مؤقتة. الأسماء يجب أن تكون بحروف صغيرة.)

## البناء عبر GitHub
1. أنشئ مستودعاً جديداً وارفع محتوى هذا المجلد (`git init && git add . && git commit -m "init" && git push`).
2. افتح تبويب **Actions** — يبدأ البناء تلقائياً عند كل push.
3. بعد انتهائه حمّل ملف الـ APK من **Artifacts** (`FastDM-debug` أو `FastDM-release`).
4. لإصدار على صفحة Releases: `git tag v1.0.0 && git push --tags`.

### توقيع نسخة الـ release (اختياري)
أضف في Settings → Secrets → Actions:
`KEYSTORE_BASE64` (الملف jks بصيغة base64) و `KEYSTORE_PASSWORD` و `KEY_ALIAS` و `KEY_PASSWORD`.
بدونها يُوقَّع الـ release بمفتاح debug ويعمل للتثبيت المباشر.

## البناء محلياً
Android Studio (Koala أو أحدث) → Open → Run. المتطلبات: JDK 17، minSdk 29.

## ملاحظات
- يُحفظ الملف أولاً في مجلد مؤقت للتطبيق ثم يُنقل إلى `Downloads/FastDM` عند الاكتمال.
- الروابط من نوع `blob:` لا يمكن تنزيلها مباشرة.
- بعض الخوادم لا تدعم الأجزاء أو الاستئناف؛ عندها يُنزَّل الملف بجزء واحد ويبدأ من الصفر عند الاستئناف.
